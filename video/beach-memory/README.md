# ساحل — Beach Memory

یک ویدیوی احساسیِ ۲۳ ثانیه‌ای (۱۰۸۰×۱۹۲۰) که فقط از **یک عکس ثابت** ساخته شده است.
با [Remotion](https://remotion.dev) رندر می‌شود و کل موسیقی و صدای آن هم با کد ساخته
شده — هیچ فایل صوتی دانلود نشده است.

A 23-second emotional piece built from a single still photograph, rendered with
Remotion. Every asset except the photograph itself is generated by the scripts in
this folder.

## اجرا / Running

```bash
npm install
npm run audio      # سنتز موسیقی → public/audio/score.wav
python3 scripts/upscale.py   # بزرگ‌نمایی عکس → public/img/beach@2x.jpg
npm run render     # خروجی → out/beach-memory.mp4
npm run studio     # پیش‌نمایش تعاملی
```

روی ماشین‌هایی که Remotion نمی‌تواند Chromium را دانلود کند، مسیر مرورگر را دستی بدهید:

```bash
npx remotion render src/index.ts BeachMemory out/beach-memory.mp4 \
  --codec h264 --crf 16 \
  --browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell
```

## ساختار / Structure

```
src/
├── theme.ts                 پالت، منحنی‌ها، فنرها، ابعاد — تنها منبع حقیقت
├── shots.ts                 «دوربین»: شش قاب‌بندی روی همان یک عکس
├── fonts.ts                 بارگذاری وزیرمتن با delayRender
├── Root.tsx                 تعریف Composition
├── scenes/BeachMemory.tsx   چیدمان لایه‌ها و متن روایت
└── components/
    ├── Photo.tsx            کن‌برنز، عمق میدان، تحویل قاب با رک فوکوس
    ├── Layers.tsx           مش پس‌زمینه، نشت نور، درخشش دریا، بوکه، گرید، دانه، وینیت
    └── Caption.tsx          زیرنویس فارسی راست‌به‌چپ با ظهور کلمه‌به‌کلمه
scripts/
├── gen-audio.mjs            سنتز موسیقی و صدا (بدون وابستگی)
└── upscale.py               بزرگ‌نمایی لنکزوس عکس مبدأ
```

## نکته‌های فنی / Implementation notes

چند تصمیم که ظاهر کار به آن‌ها وابسته است:

**دوربین.** هر «نما» یک نقطهٔ کانونی در مختصات نرمال‌شدهٔ عکس به‌علاوهٔ یک بزرگ‌نمایی
است (`src/shots.ts`). دستِ اشاره‌کننده در `x ≈ ۰٫۱۹` و لبهٔ راست دخترک در `x ≈ ۰٫۸۴`
قرار دارد؛ یک قاب ۹:۱۶ فقط `۰٫۸۴ ÷ zoom` از عرض عکس را نشان می‌دهد، پس هر نمای بازی
که قرار است کل ژست را در خود جا دهد باید حوالی `zoom ۱٫۰` و مرکز `x ≈ ۰٫۵۱۵` بنشیند.
نماهای بسته‌تر عمداً بازو را کنار می‌گذارند تا آن را از وسط نبُرند.

**تحویلِ نما.** همهٔ نماها برشی از *یک* عکس‌اند، بنابراین دیزالو ساده مرد را روی خودش
در دو مقیاس مختلف سوار می‌کند و مثل ایراد فنی دیده می‌شود. به‌جای آن هر دو طرف با یک
منحنی زنگوله‌ای (`sin(πp)`) از فوکوس خارج می‌شوند؛ اوجِ تاری دقیقاً وسط تحویل می‌افتد،
همان‌جا که هم‌پوشانی بیشترین است.

**صدا.** `scripts/gen-audio.mjs` یک WAV استریوی ۱۶ بیتی می‌سازد: بستر دریا (نویز فیلترشده
با پوش‌های موج)، پدِ گرم که آکوردهایش دقیقاً روی برش‌های تصویری عوض می‌شود، یک ملودی
پیانوییِ کم‌نُت، ضربه‌های زیرِ باس روی هر برش، و یک شیمر پیش از اوج. کاملاً قطعی —
هر بار همان فایل ساخته می‌شود.

**متن.** وزیرمتن به‌صورت محلی در `public/fonts` نگهداری و با `FontFace` ثبت می‌شود.
`delayRender` باید از داخل رندرِ کامپوننت صدا زده شود؛ صدا زدنش در سطح ماژول موقع
ارزیابی باندل خطا می‌دهد و کل Composition را از کار می‌اندازد.

## عکس مبدأ / Source photograph

`public/img/beach.jpg` — عکس شخصی، ۱۰۲۴×۱۵۳۶. نسخهٔ دوبرابرشده که رندر از آن استفاده
می‌کند از روی همین ساخته می‌شود و در گیت نگهداری نمی‌شود.
